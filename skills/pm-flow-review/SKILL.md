# 범용 플로우 검토

CLI는 `~/.local/bin/pm-flow`다. `pm-flow list`, `pm-flow pull project/category/chart --out review.json`으로 런타임 원문을 확인한다. 저장소의 초기 TS 차트는 역사적 fixture이며 정본이 아니다.

요청된 프로젝트의 실제 코드와 사용자가 확정한 업무 규칙을 기준으로 검토한다.

- 화면 노드는 사용자가 실제로 보는 화면명과 할 수 있는 기능을 갖는가?
- 자동 로직은 화면 배너 없이 실행 조건·입력·결과를 설명하는가?
- 연결선은 사용자 행동·자동 트리거·검증 조건을 설명하는가?
- OR/AND, 기본값/예외, 참조/시간 진행을 구별하는가?
- 저장, 중복 방지, 실패, 취소·역처리 경로가 필요한 곳에 있는가?
- 실선 impl과 점선 future가 코드 근거와 맞는가? 코드·단위테스트 통과를 운영 검증으로 표현하지 않았는가?
- 새 ID나 삭제된 ID로 인해 사용자 배치가 불필요하게 사라지지 않는가?
- `pm-flow validate review.json`이 통과하는가?

발견사항은 노드/선 ID, 근거 파일, 사용자 영향, 수정안을 함께 제시한다. 확인 못 한 규칙을 임의 확정하지 않는다. 검토만 요청되었다면 apply하지 않는다. 수정도 요청되면 pm-flow-author 절차로 변경하고 diff를 검토한 뒤 revision 조건 저장한다. 브라우저 확인은 명시적으로 요청된 경우만 수행한다.
