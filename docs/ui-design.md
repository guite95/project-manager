# 워크스페이스 UI

기존 네이비 메뉴와 밝은 작업 영역, 프로젝트 중심 탐색 구조를 유지한다. 주요 화면은 사이드바를 제외한 전체 폭을 쓰고, 읽기용 긴 문단만 적절한 줄 길이를 둔다.

## 공통 기준

- 색상: 네이비 `#1B2A4A`, 본문 `#17263C`, 보조 글자 `#5F6C7B`, 흰색 `#FFFFFF`, 보조 표면 `#F5F7FA`, 구분선 `#DCE3EC`. 실제 값은 `app/globals.css`의 `--bi-*` 토큰에서 관리한다.
- 글꼴: 기존 Pretendard와 한국어 시스템 글꼴 구성을 유지한다. 외부 폰트 요청을 추가하지 않는다. 기본 13px, 보조 12px, 페이지 제목 22px를 사용한다.
- 배치: 60px 아이콘 레일과 235px 상세 메뉴를 유지한다. 헤더·필터·본문의 좌측 시작점을 맞춘다. 모바일 좌우 여백 16px, 일반 화면 24px를 기준으로 한다.
- 형태: 입력·버튼은 4px, 주요 작업 패널은 6px 모서리. 그림자는 팝오버 등 떠 있는 요소에만 쓴다. 목록은 행과 구분선으로 정리한다.
- 상태: 선택한 메뉴는 옅은 네이비 배경, 진한 글자와 왼쪽 표시선으로 구분한다. 상태색은 글자·아이콘과 함께 사용한다. 키보드 포커스를 숨기지 않는다.
- 밀도: 데스크톱 입력과 기본 버튼은 36px, 작은 버튼은 32px. 모바일 공통 조작부는 최소 44px, 입력 글자는 16px로 한다. 필터와 동작은 좁은 화면에서 줄바꿈한다.
- 움직임: 사용자의 동작에 응답하는 짧은 색상 전환만 사용한다. `prefers-reduced-motion`에서는 전환과 반복 애니메이션을 줄인다.

```text
아이콘  상세 메뉴       페이지 제목                      주요 동작
 레일   프로젝트        설명
        문서 / 자료     ────────────────────────────────────────
                       필터                              검색
                       목록 / 작업 영역 (남은 전체 폭)
```

## 적용 범위와 검토

`ui-ux-pro-max`의 Data-Dense Dashboard 지침 중 정보 밀도, 행 강조, 접근성을 적용한다. 자동 추천에 포함된 홍보용 구성과 새 색상·서체 제안은 기존 컨셉 유지 요청에 맞지 않아 적용하지 않는다. `frontend-design`에 따라 반복적인 Workspace 장식 라벨을 제거하고, 실제 페이지 제목과 조작부를 강조한다.

공통 컴포넌트와 워크스페이스 메뉴, 할 일, 프로젝트 목록, 채용 문서 작업 영역에 적용한다. 플로우차트의 도메인 색과 저장된 레이아웃, 자료 원문, 공유 DB 설정과 접근 정책은 별도 영역이다.

CSS 초기화는 base 레이어에 두어 버튼 색상·글자 크기 유틸리티를 덮지 않게 한다. Zespro 스타일은 `--bi-*` 토큰을 참조한다. `bi-*` 공통 클래스는 대상을 명시한 컴포넌트에만 붙인다.

검증은 관련 단위 테스트, 타입 검사와 빌드로 진행한다. 브라우저 검증은 프로젝트 규칙에 따라 명시적 요청이 있을 때 수행한다.
