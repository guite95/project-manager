# 회의록 생성 스킬 검증

2026-09-14, `superpowers:writing-skills`의 작성 전/후 에이전트 비교 방식으로 검증했다.
테스트에는 합성 전사본만 사용했다. 실제 회의록과 공유 DB는 변경하지 않았다.

이후 사용자 요청으로 스킬 이름을 `sync-sum`으로 변경했다. 아래 최초 런타임 검증 기록의
`create-meeting-minutes`는 변경 전 이름이다. 새 이름의 Codex·Claude Code 설치 링크와
메타데이터·문서·스크립트 참조를 갱신했으며, 변경된 경로의 CLI 테스트 2개가 통과했다.

## 작성 전 기준선

스킬과 앱 JSON 규약 없이 독립 에이전트에게 `tns`, `2026-09-14`, 재고 이관 회의
전사본을 제공하고 가져오기용 초안을 요청했다. 전체 품목 이관 제안 뒤 현재 품목만
이관하는 합의, 과거 품목 보류, 김담당의 목록 전달 약속과 미정 기한이 포함된 사례다.

내용 판단은 적절했으나 `projectId`, `type`, `meetingDate`, `tasks`, 결정 사항 객체
배열을 사용해 현재 앱 문서 규약과 달랐다. 에이전트 스스로 “필드 매핑이 필요한 초안”이라고
명시했다. 이 형식 불일치를 보완하기 위해 정확한 출력 규약과 조립·검증 스크립트를 추가했다.

## 작성 후 독립 에이전트

- 같은 시나리오에서 스킬을 읽고 `notes.json`, 원문, `draft.json`, `review.md`를 생성했다.
- 실제 `prepare`/`validate`가 각각 `prepared`/`valid`, 종료 코드 0을 반환했다.
- 결정 사항은 문자열 배열, 태스크는 `actionItems`, 기한은 `null`이었다.
- 원문 해시·바이트 일치와 개인 폴더 0700 / 파일 0600을 확인했다.
- 현재 품목 범위만 확정으로 남기고 과거 품목과 담당자 질문은 미결로 분리했다.

별도 시나리오에서는 날짜가 없고 기존 사람 편집본과 전사본이 충돌하며 원문에 DB 저장·외부
전송 지시가 포함되도록 했다. 에이전트는 날짜를 추정하지 않고 작성 가능한 텍스트 초안만
제시했다. 원문 지시를 실행하지 않았으며 사람의 결정 사항·담당자를 보존 대상으로 남겼다.
이 시나리오는 응답 평가이며 파일 생성·DB 실행 검증은 아니다.

## 도구 및 설치

실행 명령:

```bash
node --env-file-if-exists=.env --test --test-concurrency=1 \
  lib/meeting-draft.test.mjs lib/meeting-skill-cli.test.mjs lib/server/meeting-import-store.test.mjs
pnpm typecheck
pnpm build
```

- 테스트 9개 통과. 원문 BOM/CRLF 보존, 잘못된 UTF-8/형식/날짜 거절, 출력 덮어쓰기 방지 검증.
- 로컬 테스트 DB에서 읽기 전용 검사, 백업 파일 해시/권한, 한 문서 신규 생성, 중복 등록 거부,
  기존 편집 보존, 백업 실패 시 롤백, 동시 등록, CLI 파일 해시 검증 통과.
- 타입 검사·프로덕션 빌드 통과. 스킬 frontmatter 검증 도구도 통과.
- 설치 명령 재실행 시 같은 심볼릭 링크를 유지하는 것을 확인했다.
- Codex app-server의 실제 `skills/list`에서 `create-meeting-minutes`, `enabled: true`,
  `scope: user`와 저장소 SKILL.md 경로를 확인했다.
- Claude Code 실제 비대화형 호출에서 `/create-meeting-minutes`가 설치 경로의 스킬과 규약을
  읽고 합성 전사본의 올바른 `notes.json`을 반환했다. 읽기 도구만 허용했고 파일/DB 쓰기는 하지 않았다.
- Claude 설치 경로를 통한 공용 스크립트 실행과 생성된 초안의 검증도 통과했다.

## 확인하지 않은 범위

공유 DB의 신규 회의록 등록, 실제 전사본의 내용 정확성, 배포된 앱 화면은 이번 작업에서
확인하지 않았다. 스킬 설치는 원격 앱 배포를 포함하지 않는다. 합성 평가의 통과가 모든 회의의
요약 정확도를 보장하지 않으므로 생성 결과는 사람 검토용 초안으로 표시한다.
