# 포커스에이아이 NotebookLM 외부 링크

- 날짜: 2026-08-06
- 상태: 설계 승인됨 (구현 전)
- 대상 노트북: https://notebook.google.com/notebook/a17b9008-778c-407a-8ca0-08bd2e8a0f2e?authuser=2

## 목표

기존 프로젝트 매니지먼트 사이드바에 `포커스에이아이` 프로젝트와
`NotebookLM` 메뉴를 추가한다. 사용자가 `NotebookLM` 메뉴를 누르면 중간 안내
페이지 없이 지정된 NotebookLM 노트북을 새 탭에서 바로 연다.

NotebookLM은 응답 헤더의 `X-Frame-Options: DENY`로 외부 페이지 임베드를
차단하므로 이 사이트 안에 iframe으로 표시하거나 제어하지 않는다.

## 선택한 접근

사이드바 전용 외부 프로젝트 링크 데이터를 추가한다. 기존 `flowProjects`에 빈
카테고리나 가짜 차트를 넣지 않고, 사이드바가 일반 플로우 프로젝트와 외부 링크
프로젝트를 각각 알맞은 UI로 렌더한다.

검토한 다른 방식:

1. 내부 안내 페이지를 거쳐 외부 링크 제공: 클릭 한 번이 더 필요해 사용자 요청과
   맞지 않는다.
2. NotebookLM을 플로우차트처럼 등록: 실제 데이터의 의미와 레지스트리 불변식을
   훼손한다.
3. 외부 링크 메뉴 직접 제공: 가장 단순하며 요청한 동작과 일치한다. 이 방식을
   채택한다.

## 사이드바 UI와 동작

- 프로젝트 이름: `포커스에이아이`
- 메뉴 이름: `NotebookLM`
- `NotebookLM` 행 오른쪽 끝에 우상향 외부 링크 아이콘을 표시한다.
- 텍스트, 빈 공간, 아이콘을 포함한 행 전체가 하나의 링크다.
- 클릭 시 지정된 NotebookLM URL을 새 탭으로 연다.
- 링크에는 `target="_blank"`와 `rel="noopener noreferrer"`를 사용한다.
- 외부 사이트를 여는 메뉴이므로 현재 페이지 활성 상태는 표시하지 않는다.
- 기존 프로젝트 트리의 행 높이, 글자 크기, 들여쓰기, hover 스타일을 재사용한다.
- 사이드바 검색에서 `포커스에이아이` 또는 `NotebookLM`로 찾을 수 있게 한다.

## 데이터 경계

외부 링크 프로젝트 데이터는 제목과 링크 목록만 가진다. 각 링크는 표시 이름과
URL을 가진다. NotebookLM URL은 한 곳에서만 선언해 렌더링 코드에 중복하지 않는다.
플로우차트 조회, 라우팅, 목록 페이지 데이터에는 영향을 주지 않는다.

## 오류와 접근성

- 외부 링크에는 새 창 열림을 알 수 있는 아이콘과 스크린 리더용 설명을 제공한다.
- NotebookLM 로그인 또는 접근 권한 오류는 Google 페이지에서 처리한다.
- 팝업 차단에 덜 의존하도록 자바스크립트 `window.open` 대신 일반 앵커 링크를
  사용한다.

## 검증

1. `pnpm typecheck`
2. `pnpm build`
3. 사이드바에 `포커스에이아이 > NotebookLM`이 표시되는지 확인
4. NotebookLM 행의 어느 부분을 클릭해도 정확한 URL이 새 탭으로 열리는지 확인
5. 검색어 `포커스에이아이`, `NotebookLM`에서 메뉴가 노출되는지 확인
6. 기존 플로우차트 프로젝트의 접기, 펼치기, 검색 동작에 회귀가 없는지 확인
