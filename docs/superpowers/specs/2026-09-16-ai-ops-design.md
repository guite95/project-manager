# 개인 AI 활동 자동 수집

사용자가 승인한 Next.js 통합 방식으로 세션/대화/검색/사용량을 구현한다. 기존 Poooling Agent 코드는 읽기 전용 참고이며 전송 대상과 설정을 변경하지 않는다.

## 구조
- Mac의 별도 Node Agent가 Codex/Claude Code JSONL을 증분으로 읽는다. 기본 루트, CODEX_HOME/CLAUDE_CONFIG_DIR, ~/.uk-private 경로, ~/uk 아래의 .codex/.claude 및 명시적 추가 루트를 탐색한다.
- 수집 대상은 세션 cwd가 ~/uk 자신 또는 하위인 기록이다. 위치가 ~/uk 밖인 로그도 대상 cwd이면 포함한다. 심볼릭 링크는 realpath로 중복 제거한다.
- 사용자 메시지와 공개 assistant 텍스트만 수집한다. 시스템/개발자 지시, 추론 본문, 도구 본문, 자동 문맥은 제외한다. 전송 전과 서버 저장 전에 비밀값 패턴을 마스킹한다.
- 개인 SSH -> 기존 Docker 컨테이너의 고정 ingest 명령(stdin JSON) -> PostgreSQL. 별도 공개 수집 포트/장기 토큰/운영 DB 비밀번호 복사 없음.
- 기존 단일 사용자 로그인으로 조회한다. 이 앱은 사용자 계정별 분리가 없는 개인 앱이다. 다중 사용자 서비스로 확장 시 소유자 모델과 권한을 먼저 추가해야 한다.
- LaunchAgent 로그인 시 및 60초 간격, 중복 실행 잠금, ACK 뒤 원자적 체크포인트, 실패 시 다음 주기에 재시도. 본문을 로컬 상태/로그에 저장하지 않는다.

## 화면
/ai-ops/activity, /ai-ops/usage. 기기/기간(일·주·월·분기·연)/원천/모델 필터, 수동 및 가시 상태 주기 갱신, 최근 세션 목록, 페이지 단위 대화 상세, 프롬프트/응답 검색, 토큰 구성과 기간/모델별 집계, 기기별 마지막 동기화/오류 상태.

## 데이터
기기, 세션, 메시지, 사용량 이벤트를 분리한다. 수신 중복은 안정적 source/session/event 식별자로 방지한다. 본문 90일, 메타데이터/사용량 365일. 조회에서도 보관 기한을 적용하고 수집 작업에서 만료 데이터를 정리한다. null은 미제공이며 0과 다르다. Codex 캐시 입력/추론 출력은 포함 관계를 보존하여 이중 합산하지 않는다.

## 적용 경계
코드/로컬 테스트/읽기 전용 실로그 파싱 검증은 지금 수행한다. 커밋/푸시/운영 배포/공유 DB migration은 별도 결정이므로 검증된 결과를 준비한 뒤 사용자에게 구체적 반영안을 제시한다. 자동수집 설치·활성화는 배포된 intake를 확인한 뒤 수행한다. 브라우저 검증은 생략한다.
