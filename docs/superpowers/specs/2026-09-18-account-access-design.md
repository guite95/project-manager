# 계정·프로젝트 권한과 페이지 공유

사용자가 승인한 구성: 계정별 프로젝트 권한을 기본으로 하고 특정 페이지의 비로그인 조회를 보조 기능으로 제공한다.

- OWNER는 기존 개인 데이터와 AI 활동을 포함한 전체 권한을 갖는다. ADMIN은 회사 프로젝트와 계정을 관리한다. MEMBER는 프로젝트별 VIEWER/EDITOR 권한만 갖는다. 삭제는 OWNER/ADMIN 전용이다.
- 개인 프로젝트와 AI·업무 기록·전역 설정은 OWNER 전용이다. ADMIN도 개인 프로젝트 권한을 부여하거나 공유할 수 없다.
- 기존 비밀번호 로그인은 OWNER 최초 등록 전의 bootstrap 용도다. 등록 후 기존 서명 세션과 공통 비밀번호 로그인을 폐기한다. 개발 환경도 인증한다.
- 관리자 초대 링크는 48시간, 일회용이다. 사용자가 자신의 비밀번호를 등록한다. 세션과 초대·공유 토큰은 해시만 DB에 저장한다.
- 공유는 단일 flow_document에 한정한다. 기본 7일, 최대 90일로 만료시키고 관리자가 즉시 회수할 수 있다. 원본 데이터 보관기간은 변경하지 않는다. 독립 공유 페이지는 전체 메뉴·다른 문서·쓰기 API를 제공하지 않는다. 공유 대상에 전체 스냅샷을 요구하는 TNS ERD는 제외한다.
- 모든 경로는 기본 거부하며 서버에서 프로젝트 권한을 확인한다. 목록은 허용된 프로젝트로 필터링한다. 쓰기 요청은 동일 출처를 검증한다.
- 기존 DB 데이터는 변경하지 않는 추가 migration만 작성한다. 운영 적용·배포·커밋·푸시는 별도 요청 범위다. 테스트는 localhost:5432/project_management_test만 사용한다. 브라우저 검증은 생략한다.
