# AI 활동 자동 수집 구현 계획

**Goal:** ~/uk에서 실행하는 Codex/Claude Code 대화를 자동 수집하고 참조 화면의 세션/검색/사용량 기능을 제공한다.
**Architecture:** Mac Node 수집기 -> 개인 SSH stdin intake -> 기존 PostgreSQL -> Next.js 조회 API/React 화면.
**Spec:** ../specs/2026-09-16-ai-ops-design.md

- [x] 수집: lib/ai-ops/parser.mjs, discovery.mjs, collector.mjs와 scripts/ai-ops-agent.mjs. fixtures로 cwd 경계, 증분, 중복, 부분 라인, 재시도, 비밀값, 토큰 포함 관계를 검증.
- [x] 저장/API: 전용 forward migration, Prisma 모델, lib/ai-ops/store.mjs, scripts/ai-ops-ingest.mjs, /api/ai-ops 라우트. 로컬 테스트 DB에서 중복/필터/검색/보관기간을 검증.
- [x] UI: /ai-ops/activity와 usage, 공통 Dropdown/DateRangeFilter/Button, 사이드바. 조회/상세/검색/집계 오류를 명시하고 페이지를 추가 로드한다.
- [x] 운영 준비: Docker에 intake 파일 포함, LaunchAgent 설치/제거/status, README/운영 문서.
- [x] 종합 검증: 집중 테스트, pnpm typecheck, pnpm build, 실로그 scan(본문 출력·전송 없음), 변경 사항 보안 점검. 운영 적용은 별도 승인.

기존 작업 트리는 깨끗했다. 현재 작업 폴더에 구현하며 자동 커밋/푸시는 하지 않는다. DB/화면 작업은 별도 파일 소유권으로 위임하고 수집기를 직접 구현한다.

## 검증 결과

- AI 수집/잠금/저장소 집중 테스트 17개 통과. 로컬 테스트 DB 전용 격리 스키마는 rollback으로 정리.
- `pnpm typecheck`, `pnpm build`, `git diff --check` 통과.
- 전송 없는 전체 검사: 로그 730개, 대상 세션 81개, 파싱 오류 0. 현재 대화 로그의 수신 계약 검증 통과. 검사 시점의 수치이며 실행 중인 세션은 계속 증가한다.
- 서버 읽기 전용 확인: 기존 migration 2개 적용, ai_ops 테이블 없음.
- 운영 migration/배포/수집 활성화는 미실행. 별도 승인 후 DB 백업 -> 커밋/푸시/기존 배포 -> 개인 Mac 설치/첫 동기화 -> DB/API 검증 순으로 진행한다.
- 브라우저 검증 생략. 새 서버/터널을 실행하지 않았다.
