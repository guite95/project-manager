# 단계 간 전달 메모

다음 단계로 넘길 때 필요한 항목만 사용하라. 기존 대화·분석에 같은 내용이 있으면 반복 출력하지 마라. 이 형식은 편의를 위한 것이며 입력의 필수 스키마가 아니다. 전체 개인 이력을 복사하지 않는다.

## 지원 조건
- 회사·조직·정확한 직무명 / 공고 출처·확인 범위
- 문항 번호와 원문 / 빠짐없이 답할 하위 질문
- 최소·최대 또는 목표 분량 / 공백·줄바꿈·바이트 기준 / 소제목 포함 여부
- 블라인드 제한과 사용자 지정 형식

## 확인된 재료
- 필요하면 F1, F2처럼 식별자를 부여한 사용자 제공 사실과 해당 출처
- 개인 역할·행동 / 팀의 결과 / 수행 상태 / 실제로 확인된 효과
- 사용자가 밝힌 지원 이유·관심 / 회사와 연결할 수 있는 확인 사실
- 쓰지 말아야 할 주장 / 정정된 과장 / 반드시 유지할 내용

## 작성 결정
- 각 문항의 핵심 답과 선택한 경험
- 문단별 역할과 분량 계획 / 다른 문항과 구별할 관점
- 작성된 개요·초안·검토 결과 중 현재 유효한 버전
- 남은 확인사항 / 현재 자료로 안전하게 쓸 수 있는 범위

사실 상태, 역할, 숫자, 시점은 다음 단계로 넘어가도 유지하라. 요약하는 과정에서 '검토'를 '완료'로 바꾸지 마라. 비공개 사고과정을 기록하지 말고 작업에 필요한 근거·결정·미확인 사항만 기록하라.
