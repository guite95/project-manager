# 초안 출력 템플릿

## 문항 번호 · 원문

제출 본문에 해당하는 문장과 문단을 여기에 작성한다. 소제목은 선택 사항이다. 문항 제목과 검토 메모를 본문 안에 섞지 않는다.

## 작성 확인
필요한 항목만 짧게 제공한다.
- 분량: 실제 계산값 / 적용 단위 / 공백·줄바꿈·소제목 처리.
- 확인사항: 본문을 쓰기 위해 아직 필요한 실제 사실. 없으면 생략.
- 주요 변경: 기존 개요에서 핵심 주장이나 소재를 바꾼 경우에만 설명.

단일 문항·본문만 요청에서는 템플릿 제목과 확인 메모를 최소화한다. 완성할 수 없는 핵심 내용이 남으면 부분 초안이라고 명시하고 완성본으로 보고하지 않는다.

# 본문 작성 점검

지원동기: 지원 이유 자체가 있는가? 업무 소개만 남아 있지는 않은가?
두괄식: 첫 문장을 읽고 질문에 대한 답이 무엇인지 알 수 있는가?
구체성: 기술·역량 명칭 뒤에 실제 행동이나 판단이 있는가?
사실: 역할, 결과, 수행 상태를 자료보다 확대하지 않았는가?
문체: 추상적인 마무리, 같은 도입, 과도한 확신을 반복하지 않는가?
분량: 작성 후 본문을 실제로 계산했는가? 계산 방식이 분명한가?
