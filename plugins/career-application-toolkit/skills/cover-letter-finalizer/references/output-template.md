# 최종 수정 출력 템플릿

## 문항 번호 · 원문

수정한 제출 본문만 여기에 둔다. 검토 메모·인용 설명·표식을 본문과 섞지 않는다. 문항 제목은 제출 입력란에 들어가는 경우에만 본문 길이에 포함한다.

## 수정·점검 요약
사용자가 수정본만 요청하면 생략하거나 필요한 한계만 남긴다.
- 핵심 변경: 실제 변경한 내용 중 중요한 부분만.
- 분량: 최종 계산값, 단위, 공백·줄바꿈·제목 처리.
- 검증 범위: 제공 자료 기준 / 외부 확인 범위 / 일부 수정 여부.
- 남은 확인사항: 제출 판단에 영향을 주는 사항만. 없으면 생략.

핵심 사실·문항·분량이 미확인인 상태에서 '문제없음', '모든 검증 통과', '바로 제출 가능'이라고 단정하지 않는다. 합격이나 AI 탐지 통과를 보장하지 않는다.
