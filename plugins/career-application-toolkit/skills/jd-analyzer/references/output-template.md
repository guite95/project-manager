# 결과 작성 템플릿

분석 결과 작성 시 읽어라. 아래 구조를 기본으로 삼되 사용자 지정 분량·형식을 우선하고, 확인되지 않은 정보를 채우려고 추측하지 마라. 중괄호는 안내용이며 최종 출력에 남기지 마라.

## 1. 핵심 판단

{실제 개발·운영 대상, 사용자, 문제·결과물, 업무 무게중심을 먼저 짧게 설명}

{경험자료가 있으면 지원 자격 / 주요 연결 경험 / 가장 큰 확인사항을 구분해 요약}
{경험자료가 없으면 공고 자체에 대한 판단만 제시하고 개인 적합성 판단 보류를 한 번 명시}
{공고 식별정보, 자료 시점·확인 범위·필요한 최신성 한계를 짧게 표시}

## 2. 실제 업무와 요구 역량

{회사·조직·정확한 직무명, 신입·경력 및 요구 연수, 고용 형태, 근무지, 학력·전공, 마감일 중 확인된 조건을 간결하게 정리. 미기재와 자료 누락을 구별}

{실제 업무와 책임 범위를 설명. 필수·우대·담당 업무·해석상 핵심 역량을 구분. 공고 요구사항이 업무에서 필요한 이유를 설명}

## 3. 내 경험과의 매칭

경험자료가 있을 때:

| 구분 | JD 요구사항 | 관련 경험·근거 | 판단 | 차이 또는 확인사항 |
| --- | --- | --- | --- | --- |
| {필수/우대/담당 업무/해석상 역량} | {원문 조건 보존} | {경험 상태, 개인 행동, 문서·구절} | {충족/부분 충족/미충족/정보 부족} | {요구 수준과의 차이} |

경험자료가 없으면 제목을 **3. 요구사항별 준비 근거**로 바꾸고 다음 표를 사용하라:

| 구분 | JD 요구사항 | 업무상 의미 | 보여주면 좋은 경험·산출물 |
| --- | --- | --- | --- |
| {필수/우대/담당 업무/해석상 역량} | {원문 조건 보존} | {필요한 이유} | {사용자가 보유했다고 단정하지 않는 예시} |

## 4. 지원서와 면접에서 강조할 내용

{경험자료가 있으면 최대 3개 경험. 각 항목에 JD 연결, 개인 행동·기여, 근거, 강조 관점, 표현 범위·주의점을 포함. 표와 중복되는 세부 근거는 참조만}

{경험자료가 없으면 준비하면 좋은 경험 유형·증빙 방향만 간단히 제시. 특정 개인 경험을 선정하거나 존재한다고 암시하지 말 것}

{완성 자기소개서나 요청하지 않은 예상 면접 질문은 넣지 말 것}

## 5. 보완 과제와 추가 확인사항

{자격 조건 / 실무 역량 차이 / 설명·증빙 부족 / 우대사항으로 구분하고 의사결정에 중요한 순서대로 구체적 행동 제시}

{결론을 바꿀 핵심 질문만 마지막에 묶기. 접근 실패 시 원문 전체를 무조건 재요청하지 말고 빠진 필수·우대 구간, 정확한 직무명 등 필요한 범위만 요청}

## 복수 공고의 적용 방식

위 1~5의 순서를 유지하되 1에서는 비교 결론을, 2에서는 업무·조건 비교표를, 3에서는 경험 연결 비교표를 중심으로 작성하라. 같은 항목을 여러 표에 중복하지 말고 간단한 경우 2 또는 3에 통합 비교표를 두고 다른 절에서는 추가 해석만 작성하라.

| 비교 기준 | 공고 A {정확한 직무명} | 공고 B {정확한 직무명} |
| --- | --- | --- |
| 실제 업무와 책임 | {근거 기반 설명} | {근거 기반 설명} |
| 필수 조건과 지원 자격 | {조건과 판단 분리} | {조건과 판단 분리} |
| 현재 경험과 직접 연결 | {확인한 경험·근거} | {확인한 경험·근거} |
| 주요 부족 역량 | {차이와 정보 부족 구별} | {차이와 정보 부족 구별} |
| 지원서에서 설득할 경험 | {핵심 경험과 강조점} | {핵심 경험과 강조점} |
| 밝힌 커리어 방향과의 관계 | {현재 적합성과 구별} | {현재 적합성과 구별} |

경험자료나 선호가 없으면 해당 판단을 보류하거나 조건부로 제시하라. 자격상의 제약과 경험 연결성을 설명한 뒤 근거가 충분할 때만 우선순위를 제안하라. 합격 확률·적합도 수치를 생성하지 마라.
